# 演示脚本

## 学生约三分钟

1. 学生甲登录，课程页展示8知识点，说明成绩与学习闭环。
2. 创建新测验，选一道单选和一道多选，刷新验证草稿。提交时说明未答按零分，确认后展示实际新成绩与诊断。
3. 历史报告进入 report-a-001，核对13/24与54.17分、不同知识点状态；展开引用并进入真实可阅读的自编资料。
4. 推荐页展示资源和练习入口。回完整报告创建以本次为基准复测，说明baseline固定。时间不足可展示已核验的report-a-002比较，明确它是预置演示记录，不能冒充刚刚新作答结果。
5. 展示report-a-004，说明2/2的100%正确率仍是证据不足，未覆盖知识点不是0掌握。

## 教师简短路径

教师登录 → 教学概况查看甲乙 → 修改课程简介并刷新 → 题库编辑标准答案（仅教师可见） → 创建文本资料或上传TXT → 查看处理状态。

## 故障备选

故障演示请另开本地调试模式 `npm run dev:debug`（5175），不要在默认5173展示界面寻找场景控制。调试端和展示端的数据按端口隔离。对外主线保留“示例数据”标识，不把模拟链路表述为真实模型调用。

模型降级：场景model-fallback，报告保留规则统计并明确模板模式。整体诊断失败：新测验前选diagnosis-failed，成绩保留，按服务能力重试。网络提交响应丢失：选submit-committed-response-lost，新测验提交后查询同一记录恢复。

运行截图在 testing/frontend/screenshots。需要录屏时，在标准浏览器按上述路径实际操作，用系统录屏保存；录屏标题注明模拟模式、数据版本和日期。未生成虚假视频。现场前确认端口、依赖、浏览器与种子版本；不用未验证配置替换。
