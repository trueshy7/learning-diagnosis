# 演示数据与场景

数据为原创课程设计样例，不包含真实学生或外部教材版权声明。规则 mock-rule-v1，数据 mock-data-v1，报告 mock-report-v1。

8 个知识点、64 道不同题干的客观题，每点8道主关联，16道多选。每点01—03用于前测，04—06用于复测，07—08用于练习。4道练习题具备多知识点关联。标准48道前后测题均为单知识点。

20条独立有正文资料：8概念、8操作、4综合复习。章节可回到实际正文；不伪造文献页码，文本 page_start/page_end 为 null。资料默认不依赖外网。

## 场景面板

2026-10-23起，默认5173展示界面不提供开发控制。以下面板仅在 `npm run dev:debug` 的5175或E2E调试模式可用；账号说明只出现在本地调试面板。不同端口的演示存储相互隔离，不能用5175重置5173。

右下角展开后选择场景并应用。已有页面需重新加载或进入目标页。weak-profile、balanced-profile、insufficient-coverage 在学生甲登录时进入对应预置报告；其他场景控制当前模拟服务行为。

- normal：实际模拟作答和持久化。
- empty-history / empty-recommendations：空历史/空推荐。
- retrieval-empty：测验统计正常，检索证据为空。
- model-fallback：模板降级报告，仍保留成绩。
- diagnosis-failed / diagnosis-stuck：新任务失败/持续running，验证重试和有限轮询。
- session-expired：将现有会话失效，下一次请求回登录；不影响重新登录。
- forbidden：通过真实角色边界访问教师接口或他人报告，仍返回403；不伪造成功。
- submit-committed-response-lost：先保存新提交，再丢失响应，查询恢复原记录。
- resource-removed：来源接口410，历史片段保留。
- upload-failed：上传受理后处理失败；重试可回到normal。
- invalid-response：报告/任务返回非法结构，被schema拒绝。
- long-content：长题干、说明与建议。

重置需确认，只清理本应用 IndexedDB 演示仓储和会话。完整响应样例在 examples 中；它们仅为接口协作材料，不参与真实构建。
