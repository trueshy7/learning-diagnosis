# 页面与交互流程

学生流程：登录 → 课程列表 → 课程详情 → 创建测验 → 作答 → 确认提交 → 查询成绩和诊断 → 推荐 → 资料/练习 → 复测 → 报告比较。

教师流程：登录 → 教学概况 → 学生授权报告；课程、知识点、题库、资料四类维护页面；上传后可从资源列表重新打开任务。

| 路由                                        | 页面责任                              | 原任务 |
| ------------------------------------------- | ------------------------------------- | ------ |
| /login                                      | 账号密码、错误、过期、安全返回路径    | A2     |
| /courses                                    | 从接口取得课程，空态/失败             | A1/A3  |
| /courses/:courseId                          | 说明、知识点、新建/继续测验、最新报告 | A3     |
| /attempts/:attemptId                        | 单选多选、导航、草稿、提交确认与恢复  | A3/A7  |
| /attempts/:attemptId/diagnosis              | 独立成绩、有限任务轮询、知识点与引用  | A4/A7  |
| /reports                                    | 历史分页和类型筛选                    | A5     |
| /reports/:reportId                          | 完整报告、来源、比较及下一步          | A4/A5  |
| /reports/:reportId/recommendations          | 推荐顺序、资料、练习、固定基准复测    | A5     |
| /resources/:resourceId                      | 受控来源阅读与文件获取                | A4     |
| /teacher/overview                           | 聚合统计、学生搜索与授权记录          | A6     |
| /teacher/course                             | 当前课程编辑                          | A6     |
| /teacher/knowledge-points                   | 搜索、创建、编辑、受限停用            | A6     |
| /teacher/questions                          | 分页筛选、标准答案、编辑、停用        | A6     |
| /teacher/resources                          | 元数据、关联、正文、文件上传与任务    | A6     |
| /teacher/students/:userId/reports/:reportId | 专用教师授权报告接口，只读展示        | A6     |
| /403 和未知路径                             | 保留身份，返回本人首页                | A2     |

桌面侧栏承担主导航，顶栏显示角色，主内容按阅读顺序展示。草稿/提交/高影响停用分别确认；操作成功以接口完成为准。样例原型由本次可交互页面体现，运行截图与设计代码可对应核查，未伪造团队原型评审。
