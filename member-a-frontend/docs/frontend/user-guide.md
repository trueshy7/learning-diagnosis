# 学生与教师操作说明

默认展示地址5173不提供开发面板，仅保留示例数据标识。故障测试需使用 `npm run dev:debug` 的5175；二者存储独立，详见README。普通用户不会看到内部ID、规则版本、请求追踪或服务原始异常。

## 学生

1. 登录后进入“我的课程”，选择数据结构基础。开始新测验前也可继续尚未完成的一份测验。
2. 使用题号导航或上一题/下一题切换。单选只选一项，多选可取消已选项。选项在当前标签页保存草稿，刷新后先查询服务状态，再恢复草稿。
3. 点击提交，确认已答/未答数量。允许空答提交，未答计零。提交后不能修改本次答案。
4. 请求失败时保持“待确认”，不要重新创建试卷。使用“确认服务端状态”；已提交会自动恢复成绩，未提交可按原内容重试或确认后返回编辑。
5. 诊断处理中仍能看到已经保存的成绩。到等待上限可稍后手动查询；任务失败不等于成绩丢失。只有服务允许时可以重试。
6. 阅读知识点题量、正确率与状态。2/2虽然正确率100%，题量不足仍不能判断已掌握。未覆盖不是零分，检索无证据也不是测验覆盖不足。
7. 展开引用查看保存片段与章节，点击原资料进入阅读页。失效来源显示410提示，返回报告仍能看到历史片段。
8. 在推荐页打开资料或开始推荐练习。复测始终以当前查看报告对应测验为基准。完整报告说明可比性、题量、难度与百分点变化。
9. 历史报告可按类型筛选、分页。退出会清理当前标签页的令牌与草稿，其他账号不会读取原账号私有数据。

## 教师

1. 教学概况可搜索学生，查看全部测验或最新授权报告。报告详情为只读，不会替学生创建复测。
2. 课程设置修改标题和简介，保存后刷新核对。
3. 知识点可新增、编辑、搜索、停用。有启用题目关联时服务会拒绝停用，需要先调整关联。
4. 题库可筛选题型、知识点、状态。编辑题干、2—6选项、答案、知识点、难度、解析。多选至少两个正确项，单选恰好一个。删除正确选项时重新核对答案。
5. 资源可新建有正文的文本或http/https链接，关联知识点。停用需确认，不再进入新推荐，历史报告保留片段。
6. 上传TXT/MD或文本型PDF，不超过10MiB。选择标题与知识点后提交；受理成功后继续看任务状态。失败显示原因，可按服务能力重试。文件名含scan/empty或空文件用于模拟无文本失败。
7. 刷新后可在资源列表“查看处理”恢复document/task。取消上传不显示成功；若受理与取消同时发生，刷新资源列表确认服务事实。

模拟模式中的PDF处理不做OCR、解析或嵌入。正式文件限制、权限、资源处理和模型解释需后续由B/C/D联调验证。
