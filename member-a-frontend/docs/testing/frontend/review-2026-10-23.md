# 对外展示复核与接口交付记录

日期：2026-10-23，Asia/Shanghai。范围：成员 A 前端、模拟 HTTP 契约、真实接口适配器、构建产物与 Chromium 自动化。正式 B/C/D 后端尚未提供；本文不代表全平台上线验收。

## 已修复的问题

| 发现                                                 | 修复与验证                                                                                |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 演示口令、故障场景、延迟与重置控件不适合普通展示     | 默认展示模式不显示开发面板、不注入全局控制；仅本地 debug 模式启用。真实及展示构建扫描通过 |
| 内部 ID、版本、原始任务状态影响展示且暴露实现细节    | 普通页面隐藏内部标识、改为中文状态；保留用户需要的来源与生成日期                          |
| 服务错误及 schema 校验可能透出内部字段或路径         | 统一安全中文错误和字段名；请求追踪信息仅调试显示，单元测试验证秘密路径不回显              |
| 没有真实执行步骤时仍出现 Agent 区域                  | 仅调试且有真实步骤数据时展示；示例/基础统计/AI/缓存解释明确区分                           |
| 教师学生记录只取前 50 条，切换时可能残留旧数据       | 改为服务端分页与过期请求隔离；用 61 条记录测试第 7 页及切换学生                           |
| 合法的两位小数正确率可能被拒绝，报告与测验一致性不足 | 接受正常舍入；校验报告归属、测验、计分版本、成绩、知识点统计和比较差值                    |
| 下载可能接受 HTML 错误页，文件响应 401 未正确退出    | 校验 MIME，401 先失效会话，安全保留文件扩展名；不新开可执行内容窗口                       |
| 旧引用可能静默打开新版本资料                         | 来源请求携带 resource_version；不可用返回 410，保留历史引用片段                           |
| 推荐/复测请求变更后可能沿用失败请求的幂等键          | 按报告、类型和题目意图隔离幂等键                                                          |
| 损坏的本地提交草稿可能锁住操作                       | 校验提交意图、快照与选项，不合法记录丢弃                                                  |
| 通过编辑表单停用未要求确认                           | 题目、知识点、资源编辑停用也需确认                                                        |
| 删除中间选项后标签可能跳号                           | 重排展示标签并保留稳定选项 ID                                                             |
| 空态用词不准确，上传原生按钮显示英文，长表单不易操作 | 角色相关空态、中文选文件按钮、弹窗内滚动；截图复核通过                                    |
| 多套浏览器测试争用输出目录                           | 分离 mock/showcase/real 产物目录，完整重跑通过                                            |

用户界面不应显示数据库路径、SQL、堆栈、密钥、模型提示词、令牌、正确答案数据或开发控制。教师按权限维护题库时显示答案是正常业务功能；学生作答接口及界面不得提前提供答案。隐藏界面字段不能代替后端权限控制。

## 展示与正式环境

- `npm run dev`：5173，示例数据展示，保留诚实的“演示环境 · 示例数据”标识，无开发面板。
- `npm run dev:debug`：5175，本地故障与重置测试。不同端口的数据独立。
- `npm run dev:real`：5174，访问真实 API，后端缺失显示失败，不自动回落示例。
- 默认 `npm run build` 输出真实模式；mock 构建含浏览器本地示例题库和答案，仅能使用原创公开样例，不得承载保密试题或真实学生安全边界。

## 仍需完善、确认的功能

1. B/C/D 正式联调：鉴权授权、服务端计分、快照与事务、幂等恢复、持久化、教师课程范围均需真实服务验收。前端校验不能替代后端。
2. 资料解析、向量检索、模型解释与 Agent 执行由 C/D/B 实现。当前上传模拟只保存文件与处理状态，不冒充真实解析；无证据、失败与降级已有页面状态。
3. 正式部署的 HTTPS、API 代理、CORS、真实账号、日志脱敏与 history fallback 仍需配置和验收；不能直接把模拟环境作为生产平台。
4. 注册、找回密码、自动刷新令牌未实现。若平台面向公开用户而非教师预设账号，需团队确认是否纳入下一版范围。
5. 已验证 Chromium 桌面流程；人工验收、Edge/Firefox、移动端深入适配与完整无障碍检查尚未执行。
6. 学习增益只是前后测指标，不等同因果结论；资料旧版本未归档时只能保留历史片段，无法保证重新打开全文。
7. 构建仍有上游 Zod 注释提示；主包约 1.21 MB（gzip 398 KB），正式公网体验需结合实际网络评估是否继续拆分组件库。提示不影响本轮构建成功。
