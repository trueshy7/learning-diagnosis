# 成员 B 开发说明

当前实现包含 MySQL 账号、课程、选课、题库、试卷、学生测验和资料正文、PDF/DOCX 上传与原件下载业务。启动入口 `python -m app`，ASGI 入口 `app.main:app`，HTTP 无 `/api/v1` 前缀。完整接口见 [接口详细说明](接口详细说明.md)。

## 数据库与事务

配置来自根目录 `.env` 的 DATABASE_URL，驱动为 mysql+pymysql。MySQL 库及专用账号需预先存在；应用启动 create_all 仅创建缺失表，不修改已有列、索引、约束，也不删除历史表。推荐 MySQL 8.0.16+，支持 CHECK 和超时批处理的 SKIP LOCKED。模型细节见 [数据模型详细说明](数据模型详细说明.md) 和 [测验数据模型说明](测验数据模型说明.md)。

SessionLocal 使用 autoflush=False。新增父记录在新增外键子记录前显式 flush；需要即时读取修改结果时同样显式 flush。服务管理提交和回滚，提交成功后才返回成功数据，请求结束关闭会话。新增业务应复用当前用户身份和所属课程过滤，不能相信客户端传入 student_id/teacher_id。

测验写操作以课程、试卷、作答等行锁和唯一键协调。发布后只读取冻结快照进行评分，不从当前题库获取答案。学生 DTO 逐字段构造，禁止返回含标准答案的数据库快照。新接口需覆盖越权、状态冲突、失败回滚及历史不变等业务边界。

## 测试

安装 requirements-dev.txt，运行 README 中列出的当前回归文件。默认测试使用数据库会话和 SMTP 替身、MySQL SQL 方言，不访问真实邮箱或业务数据库。

- tests/test_exams.py：题型及参数、评分、知识点样本不足、发布快照、保存版本、整批原子校验、期限边界、权限、幂等提交及导出格式。
- tests/test_mysql_exams.py：设置 TEST_MYSQL_URL 后才运行，创建独立随机临时 MySQL 库，验证真实外键、登录和端到端测验；结束删除该临时库。需要测试账号的建库和删库权限。
- tests/test_resources.py：资料字段、权限、选课、归档、版本、标签、列表与故障回滚。
- tests/test_resource_files.py：真实 PDF/DOCX 字节、表单、原件权限、大小/结构限制和存储故障。
- tests/test_mysql_resources.py：独立随机 MySQL 库中的真实登录、资料 CRUD、中文长正文、权限及复合外键。
- tests/test_internal.py：服务权限隔离、课程范围、摘要、回报幂等、版本/删除保护及完整诊断输入。
- tests/test_mysql_internal.py：显式配置 TEST_MYSQL_URL 后验证状态同事务回滚、行锁和迟到回报、迁移重跑及真实测验导出。
- tests/test_diagnosis_tasks.py：自动/手动入队、权限、冻结输入、HTTP 回执校验、重试和租约恢复。
- tests/test_mysql_diagnosis_tasks.py：独立 MySQL 验证评分/任务原子性、并发领取、跨会话读取、重启重试及迁移。
- tests/test_backend.py：依赖历史 SQLite、静态课程和旧路径，未迁移，不包含在当前推荐命令中。

不得把替身测试通过描述成已经验证真实 MySQL 并发或邮件投递。外部项目脚本仍可能引用旧入口，前端需按当前接口文档联调。

## 后续协作

当前测验已经产生稳定的题目、知识点、作答、评分及证据题目 ID。B 已实现资料持久化、上传下载和内部数据出口；C 主动拉取正文及版本，回报索引状态。测验结算默认与成绩同事务创建诊断通知，独立 worker 冻结输入后向 D 交付 task_id/attempt_id。详见 [诊断任务交付说明](诊断任务交付说明.md) 和 [内部数据接口与联调说明](内部数据接口与联调说明.md)。C 的拉取进程及 D 任务接收端/新模型需对应成员适配；B 不调度 C，不保存最终报告，旧教师导出保留原兼容。
