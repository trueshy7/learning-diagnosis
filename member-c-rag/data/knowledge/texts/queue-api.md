# enqueue dequeue 与读取队头

## 概念与约定

enqueue 把新元素追加到队尾；dequeue 删除并返回队头元素；front 或 peek 只读取队头，不删除。队列是否为空，应通过约定状态或长度判断，而不是通过队头元素是否等于零来猜测。

## 状态推演

空队列依次 enqueue(A)、enqueue(B)，读取队头返回 A，队列仍为 [A,B]；dequeue 返回 A，队列剩余 [B]。继续加入 C 后为 [B,C]，下一次出队仍返回 B。

## 边界与自查

空队列出队要明确失败方式。对动态链队列，入队还可能因为分配失败而失败；对固定数组队列，还需检查容量。接口测试应同时验证结果和状态，避免返回值看似正确但头尾指针已经错位。
