# 广度优先搜索为什么使用队列

## 概念与约定

广度优先搜索从起点出发，先访问距离起点一条边的顶点，再访问两条边的顶点。FIFO 队列保存已经发现但尚未展开的顶点，使较早发现的同层顶点先被处理，从而保持按层推进。

## 状态推演

从 A 出发，A 邻接 B、C，B 邻接 D，C 邻接 E。展开 A 后队列为 [B,C]；展开 B 时把 D 放到队尾，队列为 [C,D]，不会跳过 C 先展开 D。随后展开 C 放入 E，得到 [D,E]。

## 边界与自查

通常在顶点入队时标记已发现，避免同一顶点被不同前驱重复入队。在无权图或所有边等权的图中，BFS 可求从起点出发按边数计的最短距离；不能直接把这条结论用于任意带权最短路。
