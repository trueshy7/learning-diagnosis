# 循环队列保留空位的判空判满

## 概念与约定

循环队列把数组的首尾在逻辑上连接。若 front 指向当前队头，rear 指向下一次写入位置，且保留一个空位，则队空为 front == rear，队满为 (rear + 1) % capacity == front。这里 capacity 是实际数组长度，可容纳元素数最多为 capacity-1。

## 状态推演

数组长度为 4，初始 front=rear=0。依次入队 A、B、C 后 rear=3，队列已满；出队 A 后 front=1，再入队 D 写入下标 3 后 rear 回到 0，形成跨数组尾部的逻辑连续队列。

## 边界与自查

这组公式依赖保留空位和指针含义。若采用额外计数器或满标志位，可以使用全部数组单元，但判满规则要同步改变。讲解时先说明约定，再写公式，不能从另一种实现中随意搬来条件。
