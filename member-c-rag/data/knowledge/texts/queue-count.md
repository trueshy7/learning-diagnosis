# 使用计数器的循环队列

## 概念与约定

循环队列可额外维护 count 表示当前元素数。这样空队列为 count==0，满队列为 count==capacity，可以利用全部数组容量。front 和 rear 即使相等，也不能单凭它们判断是空还是满，需要结合 count。

## 状态推演

数组长度为 3，初始 count=0。成功入队时写入 rear、移动 rear，并把 count 加一；成功出队时读取 front、移动 front，并把 count 减一。装入三个元素后 count=3，front 与 rear 可能再次相等，但此时是满队列。

## 边界与自查

失败的入队和出队都不得改变 count。任何时刻都应满足 0≤count≤capacity。维护计数器会增加一个需保持一致的状态变量，测试中应核对元素数量、指针移动和访问值，而不仅是是否抛出异常。
