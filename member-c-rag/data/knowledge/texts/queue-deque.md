# 普通队列与双端队列的边界

## 概念与约定

普通队列只在队尾入队、队头出队。双端队列允许在两端进行插入和删除，因此可以按不同接口限制模拟队列或栈。容器名字不能代替具体操作序列的分析。

## 状态推演

用双端队列尾部追加、头部弹出，得到 FIFO 行为；若都在尾部追加和弹出，则得到 LIFO 行为。模拟时先标清左右两端分别对应什么角色，再逐条执行，不能中途交换含义。

## 边界与自查

Python 的 collections.deque 提供 append、appendleft、pop、popleft 等方法，可用于课程实验。按索引随机访问不是双端队列最主要的优势。选择容器时应根据所需操作及其成本，不能只比较某一次运行时间。
