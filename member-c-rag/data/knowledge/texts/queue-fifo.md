# 先进先出与队头队尾

## 概念与约定

队列是一种受限线性结构，通常在队尾插入，在队头删除。先进先出表示较早进入且尚未移除的元素优先离开，英文缩写为 FIFO。队头是下一次出队的位置，队尾是下一次入队的一端。

## 状态推演

依次让 A、B、C 入队，连续出队得到 A、B、C。若先让 A、B 入队，再出队 A，然后让 C 入队，剩余顺序仍为 B、C。新元素不能因为最近到达就插到所有旧元素前面。

## 边界与自查

普通队列、优先队列和双端队列有不同操作约定。优先队列按优先级选择元素，不保证一般的先来先出；双端队列允许两端插入删除。不能仅因名称中含有队列，就把所有容器的顺序规则混为一谈。
