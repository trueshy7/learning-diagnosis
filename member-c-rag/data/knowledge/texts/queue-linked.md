# 链队列最后一个元素出队

## 概念与约定

链队列通常维护头指针和尾指针。入队把新节点接到尾部；出队移除头部节点。若没有哨兵节点，空队列常约定头尾均为空。只有一个元素时出队，会使结构从非空变为空，需要同时更新头尾。

## 状态推演

队列仅有节点 A，head 和 tail 都指向 A。弹出 A 后，应把 head 和 tail 都置为空。若只移动 head 而保留旧 tail，下一次入队可能错误地连接到已经移除的节点，造成结构损坏。

## 边界与自查

使用哨兵头节点的链队列有另一套空状态约定，通常保留哨兵并让尾指针回到哨兵。两种实现都可以，但必须统一。维护尾指针可使链队列在尾部入队无需遍历，常见基本入队和出队为 O(1)。
