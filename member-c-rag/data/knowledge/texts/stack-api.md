# push pop peek 的区别

## 概念与约定

push 把新元素加入栈顶；pop 删除并返回当前栈顶；peek 只读取当前栈顶而不删除。接口也可使用 top 作为读取操作的名称。无论具体名称如何，都应明确读取是否改变容器状态。

## 状态推演

初始空栈，push(A)、push(B) 后栈为 [A,B]。peek 返回 B，栈仍为 [A,B]；pop 返回 B，栈变为 [A]；再次 peek 返回 A。若把 peek 当作 pop，后续所有状态和返回值都会推演错误。

## 边界与自查

空栈上的 pop 和 peek 都需要明确定义失败行为，例如抛出约定异常或返回一个与合法值不同的空状态。不能在可能存储整数零的栈中，把返回零无条件解释为空栈。调用者需要根据接口约定检查结果。
