# 顺序栈的 top 与容量检查

## 概念与约定

顺序栈通常用数组和栈顶下标保存状态。若约定 top 指向当前最后一个有效元素，空栈 top=-1，当前元素数为 top+1。压入前先检查 top 是否等于 capacity-1；弹出前先检查 top 是否为 -1。另一种约定用 top 指向下一空位，其边界公式不同，两种写法不能混用。

## 状态推演

容量为 3、top 初始 -1，压入 A 时先把 top 增为 0，再写入数组第 0 项；继续压入 B、C 后 top 为 2，再压入必须报告满栈或扩容。弹出时先读 array[top]，再把 top 减一，不能先减一而漏掉原栈顶。

## 边界与自查

固定容量数组压入和弹出均可为 O(1)。动态数组扩容时可能复制已有元素，因此单次压入不保证最坏 O(1)；采用按倍数扩容时，一系列压入的均摊成本可以为 O(1)。复杂度说明应区分最坏和均摊口径。
