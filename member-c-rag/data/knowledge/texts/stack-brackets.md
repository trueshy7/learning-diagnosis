# 括号匹配与不匹配定位

## 概念与约定

括号匹配可以用栈记录尚未匹配的左括号及其位置。遇到左括号就压入；遇到右括号时，栈必须非空，且栈顶左括号类型必须与它对应，满足条件才能弹出。遍历结束后栈仍非空，说明有左括号缺少对应右括号。

## 状态推演

序列 ([{}]) 可依次配对。序列 ([)] 虽然左右括号数量相等，但遇到 ) 时栈顶是 [，类型不匹配，应立即报告该位置错误。因此只统计括号数量或分别计数，不能验证嵌套顺序正确。

## 边界与自查

仅检查括号字符时，对长度 n 的输入时间为 O(n)，最坏辅助空间 O(n)。若要处理完整程序，还必须由词法规则识别字符串和注释中的括号，不能把里面的括号无条件当作代码结构。
