# 函数调用栈与递归返回

## 概念与约定

函数调用会保存返回位置和局部状态。调用进入更深层函数时，新状态压到旧状态之上；当前调用完成后，先恢复最近尚未完成的调用。这种嵌套返回关系适合用栈描述。递归与栈有关，但递归不等于算法时间复杂度高，仍需分析调用次数和每次工作量。

## 状态推演

计算 factorial(3) 时先等待 factorial(2)，后者又等待 factorial(1)。到达终止条件后，返回顺序为 factorial(1)、factorial(2)、factorial(3)。每一层都应保存自己的参数，不能用一个共享参数覆盖全部层的状态。

## 边界与自查

递归应有能到达的终止条件，并使问题向更小规模推进。深度过大可能耗尽调用栈空间；在必要时可改写为显式栈。显式栈仍需要保存恢复计算所需的信息，不能只保存函数名。
