# 链栈为什么在链表头部操作

## 概念与约定

单链表实现栈时，通常把链表头作为栈顶。入栈先新建节点，让新节点 next 指向旧头，再把头指针改为新节点。出栈保存旧头的值和 next，把头移到 next，再释放或解除旧节点的引用。

## 状态推演

原链为 B→A，压入 C 后为 C→B→A；弹出 C 后恢复 B→A。头指针为空表示空栈。链栈无需像固定数组那样预先规定容量上限，但仍可能因为内存分配失败而无法继续压入。

## 边界与自查

头部压入和删除都不需要遍历，单次操作通常为 O(1)。若把单链表尾部当栈顶，即使保存尾指针，删除尾节点仍可能需要寻找它的前驱，成本可达 O(n)。这说明物理实现位置会影响基本操作成本。
