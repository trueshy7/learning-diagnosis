# 交错入栈与出栈序列

## 概念与约定

入栈和出栈可以交错进行。判断输出序列是否合法，要保留一个模拟栈，按输入顺序逐个压入，在栈顶等于期望输出时弹出。仅把全部输入逆序，只适用于先全部入栈再全部出栈的特殊情况。

## 状态推演

输入依次为 1、2、3，可以先压入 1 和 2，再弹出 2，压入 3 后弹出 3，最后弹出 1，因此输出 2、3、1 合法。输出 3、1、2 不合法：为了先输出 3 必须已经压入 1、2、3，弹出 3 后栈顶是 2，不能越过 2 直接弹出 1。

## 边界与自查

模拟过程中，每个元素最多入栈一次、出栈一次，输入长度为 n 时可在线性时间内验证候选序列。若记录显示试图从空栈弹出，应报告操作非法，不应补造一个值继续推演。
