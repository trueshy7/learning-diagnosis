# 成员 C 检索评测报告

执行日期 2026 年 11 月 16 日。结论针对本项目新编小型语料和固定问题集，不代表真实教材、教学效果或一般检索质量。评测主集使用组长已存在的知识点 ID；扩展集含未获 B 确认的新知识点。问题与参考来源均预先写入 JSON，正式验收必须补上复核记录。

## 口径

每组恰好 20 条可回答问题，Top-5 中同时命中预标注资源 ID 和完整相关原文摘句才算命中。Hit@5=命中问题数/20，目标为至少16/20。无答案问题另设3条，不进入该分母。半数问题只限定课程和资源范围，半数再按知识点过滤。引用有效性逐项检查课程、资源、文档和精确原文字符区间。

比较400字符与60重叠、700字符与100重叠两种配置。关键词最低覆盖率0.20；语义相似度阈值0.45。耗时为本机实际测量，每题一次，包含检索必要的本地读取、范围过滤和查询，不含下载及建库；样本很小且没有并发压力测试。P95使用20次观测中的第19个顺序统计量。建库耗时另存JSON。

## 失败与改进

关键词配置未命中的 Q11 是“排队等待时较早到达的人先处理，对应哪种顺序原则”。该问法和资料用词差异较大，词项覆盖率0.15，低于0.20，因此返回不足而未把弱匹配当成证据。较低门槛虽可命中该题，却会使无答案问题返回仅含“数据”“时间”等泛词的片段。本次保留失败并交由语义检索或后续独立验证集改进，没有为消除失败而改写参考答案。

参数比较结果不能据此证明最优切分。现有独立资料最长约407字符，400/60与700/100的有效差异很小，后续应加入有合法来源的长教材、跨章节问题和更独立的盲测集。无答案只能测量这3个案例，单靠向量阈值不能保证自动判断所有无答案查询。

## 引用与功能验证

自动测试共36项，包括旧接口兼容、正常/空/扫描型/加密/文本PDF、页码、去重、更新删除重建、墓碑、跨课程、版本范围、摘要、查询限制、提示性文本、编造/失效引用、真实Chroma持久化、嵌入数量维度和非有限数、故障降级及B同步合同。真实Chroma功能测试的hash_test明确标为测试向量，与上面的语义评测分开。

D到C使用实际回环HTTP和仓库D检索代码，记录在 d_http_integration_*.json；B接口同步测试使用MockTransport，不代表真实MySQL或组长运行环境已联通。D仍是规则模板，未执行LLM解释，这不是模型正常闭环验收记录。
